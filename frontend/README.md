# OMT Frontend

一个基于 **Next.js + TypeScript** 的本机 Agent 前端。浅蓝色界面，提供模型配置、全局运行设置、SSE 增量聊天、独立 reasoning、工具记录和明确的执行反馈。

![浅蓝色首页预览](docs/images/workspace.png)

[查看窄屏界面](docs/images/workspace-mobile.png)

> 第一版只面向可信本机、单用户环境。不是面向公网的部署方案，也不包含独立的模型后端。

## 环境

- Node.js **22.19+**（建议使用 Node.js 22 LTS 或更新的受支持 LTS）
- npm，依赖使用 `package-lock.json` 锁定
- 已运行的 OMT HTTP 后端（支持 runtime 配置与 OMT v1 SSE），默认地址 `http://127.0.0.1:8000`；未配置模型也可以启动
- 当前后端无需访问令牌；厂商模型 API Key 可通过前端密码框提交给本机后端进行预览，明确确认后才保存

后端接口和操作限制见 [前端接入契约](docs/frontend-api.md)。其中指向后端配置、源码和测试的链接属于后端仓库，不一定存在于本项目。

## 开发启动

```bash
npm ci
cp .env.example .env.local
npm run dev
```

打开 **http://127.0.0.1:3000**。

默认配置已指向本机 8000 端口；只有需要修改后端端口时才编辑 `.env.local`：

```dotenv
OMT_BACKEND_URL=http://127.0.0.1:8000
```

这是服务端配置，修改后重启 Next.js。只允许本机回环 HTTP(S) origin，不支持带路径、用户名或密码的地址。无需配置 Bearer 令牌，不要将模型凭据放入 `NEXT_PUBLIC_*` 变量。

1. 打开页面自动只读探测运行状态和本地目录，不会创建会话、保存配置或执行消息。
2. 未配置或未就绪时，点击左侧栏底部的“添加模型”（窄屏先展开会话导航）：选择厂商 → 输入 API Key（已有凭据可留空复用）→ 获取模型预览 → 选择模型 → 明确确认保存并尝试启用。Key 提交后立即清空，不写入浏览器存储。必须分别查看“配置已保存”和“运行实例已启用”；保存后启用失败可能仍使用旧实例。
3. 点击右上角“未连接”，在弹窗点击“连接本机后端”，无需输入访问令牌；就绪后读取会话列表。新建会话（标题可选），或选择已有会话。
4. 日常直接在消息输入框底部、发送按钮旁的紧凑下拉控件选择厂商/模型及思考强度，无需重新提交凭据。设置作用于**整个 API 进程**，并非当前会话；临时切换不改重启默认值。请求 level 与实际 reasoning_effort 分开展示，实际降为 none 时提示回退。
5. 输入消息，Enter 发送；Shift + Enter 换行。正文增量展示，reasoning 和工具输入/进度/结果独立折叠；每轮展示其 run.started 配置快照，而不是之后切换的新配置。
6. 运行中可“停止接收”；后端检测断线后尝试终止，但不承诺工具立即停止或副作用回滚。成功后同步完整历史，不重复追加最终回答；用户向上阅读时不会被新输出或历史同步拉回底部。

右上角反映最近请求的结果，不是持续在线检测。出现“连接待检查”时，可以打开连接设置并点击“检查连接”；该操作只读检查运行状态/目录，就绪时再读取会话列表，不会重发消息。顶部错误提示可以关闭；关闭提示不会改变执行状态或解除结果不明时的发送保护。

前端不输入、保存或发送访问令牌。刷新页面后点击连接即可重新读取后端会话；断开连接会清除本页面缓存和草稿，但不会删除后端会话。当前接口没有认证保护，任何能访问后端的调用方都可能触发文件或命令工具，请勿向公网或不可信网络开放。

## 本机生产模式

```bash
npm run build
npm start
```

开发及生产启动命令默认只监听 `127.0.0.1`，请勿自行绑定公网地址。需要换端口时：

```bash
npm run dev -- --port 3001
# 或
npm start -- --port 3001
```

浏览器调用 `/api/omt/*`，Next.js 将白名单接口转发到固定的本机后端，不要求浏览器直连跨域端口。代理不要求认证，也不会将 Authorization 或 Cookie 转发到后端，不跟随重定向，不自动重试写请求，并允许长时间执行。SSE 响应逐块转发、不等待整包，传递断连信号并关闭响应缓冲；部署到其他反向代理时同样需要禁用缓冲和短请求超时。

## 已实现

- 无令牌一键连接、只读连接检查、断开与请求异常提示。
- 新建会话、会话列表、会话切换、手动刷新。
- 用户 / 助手 / 工具历史，Markdown、GFM 表格和代码块。
- 工具参数和结果折叠展示；有调用 ID 时可跳转到对应调用。
- 左侧栏“添加模型”提供厂商配置预览/确认、保存与启用分离反馈；消息输入框底部直接切换全进程模型和思考强度，不再占用顶部设置栏。
- 当前消息输入、SSE 实时正文/独立 reasoning、按调用 ID 关联的并行工具卡片。
- 每轮独立停止接收、同步提交锁和会话响应隔离。
- 非致命警告、异常时的运行诊断 ID、结果不明与人工检查流程。
- 执行成功后刷新历史和列表，刷新失败时保留最终回答；提示明确区分列表读取、历史读取与执行失败。
- 发送时恢复底部跟随；增量输出、完成及历史同步不打断用户向上阅读。
- 浅蓝色背景、深蓝灰文字的响应式布局，关键文字对比度回归测试，以及原生模态框和键盘输入支持。

## 必须了解的执行语义

- 使用 OMT v1 `/runs/stream`；不是 OpenAI delta 协议，不将 HTTP 200、心跳或助手/工具完成当成整轮成功。只有运行终态能确认成功、失败或取消。
- 一次执行可能读写文件或运行命令。流式断开会尝试取消，但没有立即停止或回滚保证；没有终态的 EOF、网络异常、协议异常和主动停止均显示结果未确认。
- 发送和创建均无自动重试。创建响应丢失时，先关闭弹窗并刷新列表检查，避免重复创建。
- 默认后端全局只接受一轮执行。本页面执行期间禁用新的本地发送；其他页面或客户端仍可能造成 busy / 容量拒绝。
- 执行结果不明时，本页面阻止继续发送。可以手动读取历史并人工检查，再明确确认允许继续。**历史可读并不能证明某次丢失响应的请求是否执行过。** 也可以在连接设置中主动断开，但会丢失本页跟踪信息，不会停止后端。
- 运行成功但历史刷新失败不是运行失败；重新读取历史不会重新执行消息。
- 后端没有独立取消接口、断线续传或按 run_id 查询后台任务；也不支持删除、重命名、附件上传、重新生成或历史编辑，本项目不会伪造这些能力。
- 浏览器对单帧设 2 MiB、单轮传输设 16 MiB 接收上限（含心跳）；超过限制停止接收，提示检查历史，不静默截断或重跑。
- 消息和工具内容可能包含敏感信息。原始 HTML 不渲染，Markdown 外部图片不自动加载；仍应谨慎打开外链。

## 测试与质量检查

```bash
npm run typecheck
npm run lint
npm test
npm run build
npm run test:proxy
```

`test:proxy` 在随机本机端口启动独立 HTTP 替身及已构建的 Next.js，验证真实代理路由、配置接口 GET/POST/PUT、SSE 在 EOF 前可见、下游中止关闭上游、无认证访问、凭据过滤与路径转发；结束后关闭服务，不连接真实后端。

浏览器测试首次运行前安装 Chromium：

```bash
npx playwright install chromium
npm run build
npm run test:e2e
```

Playwright 使用 3100 端口启动生产构建，测试结束会关闭服务。测试全部采用 mock / 替身，不需要真实令牌，不会调用模型或执行真实后端工具。

部分精简 Linux 环境需要额外的浏览器系统依赖，例如 `libasound.so.2`。可先运行 `npx playwright install-deps --dry-run chromium` 查看缺失依赖，再由操作者决定是否授权安装；本项目脚本不会自动提权安装系统软件。中文截图还需要系统具备中文字体。

测试分层：
- API：请求契约、无 Authorization、路径编码、响应校验、错误及禁止重试；SSE 半帧/多帧、逐字节 UTF-8、序号/关联校验、未知事件、心跳及无终态断线。
- 控制器/纯投影：配置保存与启用分离、切换成功/忙碌/失败/回退、多助手与独立 reasoning、同名并行工具、停止、异步竞态及完整历史替换。
- React + MSW：首次配置到明确确认、真实客户端下的增量展示与成功后去重、无令牌连接、异常保护、Markdown 安全展示。
- 代理冒烟测试：构建后的真实 Next.js 路由接入隔离的本机 HTTP 替身，覆盖 Next 内部 URL 与浏览器 Host 的差异。
- Playwright：真实浏览器中的桌面/窄屏布局、完整交互、无认证连接和结果不明流程。

## 代码与扩展

先阅读 [架构文档](docs/architecture.md)，再阅读对应代码：

| 路径 | 职责 |
| --- | --- |
| `src/app/` | Next.js 页面、全局样式和代理路由 |
| `src/lib/omt-api/` | 类型契约、Zod 校验、HTTP 客户端和错误 |
| `src/lib/server/` | 固定本机上游代理 |
| `src/features/workspace/model/` | 状态、操作及竞态处理，不依赖 React |
| `src/features/workspace/components/` | 展示与交互，不直接请求后端 |
| `src/features/connection/` | 连接、只读检查与断开界面 |
| `src/features/runtime/` | 全进程状态、厂商配置与临时运行设置 |
| `src/components/ui/` | 通用界面模块 |
| `tests/e2e/` | 浏览器流程测试 |

新增接口先扩展契约、schema 和客户端，再接入功能及 UI。后续恢复认证、增加断线续传或多用户功能时，先明确新的安全及后端契约，不直接绕过当前模块。

项目协作规范见 [AGENTS.md](AGENTS.md)。未经用户允许不提交或推送 Git。
