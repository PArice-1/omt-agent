# 前端协作补充

通用约定见 [根协作规范](../AGENTS.md)。本模块使用 Next.js、TypeScript strict 和 npm。

- 修改前阅读 [前端架构](../docs/frontend/architecture.md)；涉及接入、配置、会话、消息或代理时完整阅读 [API 契约](../docs/omt/frontend-api.md)。
- 沿用客户端、状态编排、展示、页面组合和服务端代理的模块分工，保持单向依赖。主要依赖、认证或接口契约变更先说明取舍。
- 外部数据以 unknown 接入并校验，保留严格类型、显式异步状态和会话隔离，避免用断言或忽略检查掩盖错误。
- 当前使用 OMT SSE。区分接纳、运行终态、断线结果不明及成功后刷新失败；POST 无自动重试，刷新历史整体替换。
- 前端通过本机同源代理连接 backend。服务端配置及模型凭据留在浏览器包之外；当前无需 Bearer，不转发 Authorization/Cookie。
- Markdown 和工具内容按不可信输入展示，保留语义标签、键盘操作和窄屏可用性。
- 行为修改覆盖相关客户端、状态、组件或代理测试；命令见 [开发说明](../docs/development.md)，常规检查使用 mock/本机替身。
- 文档统一维护在根 docs，模块 README 链接到权威内容；目录、模块及数据流变更同步更新架构说明。
