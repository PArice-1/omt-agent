## 如何解释

- 只对有完整资料覆盖的问题评分；其余 22609 道问题被排除，不算检索失败或零分。
- 标准来自 qrels 的 `score > 0` 文档 ID；单题按不同文档 ID 计算，各题等权求平均。
- 文档级命中不等于命中了真正含答案的片段；同篇任意片段都可让该文档计为命中。
- 候选库缩小、按资料覆盖筛选问题以及有限片段检索预算都会影响难度。
- **这是本地缩小候选库的检索结果，不是完整 T2Retrieval 官方基准，也不衡量生成回答正确性。**

原始报告保持运行时内容不变，JSON 中的绝对路径记录生成环境；在其他机器复现时使用本机的数据与数据库路径。原始 Parquet 不随仓库提交，按上游数据集的许可与使用要求下载使用。报告记录了 corpus、queries 和 qrels 的 SHA-256，可用于核对输入版本。

数据库会随写入变化。为了保留该基线，新的实验应使用新集合和新的报告文件名；报告入口会拒绝覆盖同名文件。
